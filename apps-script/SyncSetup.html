네이버페이 자동 동기화 연결

  1. Apps Script 편집기에서 배포 → 새 배포 → 웹 앱을 선택합니다.
  2. 실행 사용자는 본인, 액세스 사용자는 모든 사용자로 설정합니다. 웹 앱은 아래 임의 토큰이 맞는 요청만 처리합니다.
  3. 배포 후 받은 /exec 실행 URL과 아래 토큰을 Chrome 확장 프로그램 설정에 입력합니다.
  4. 네이버페이 결제내역 페이지에서 가계부 자동 동기화를 누릅니다.
토큰은 비밀번호처럼 보관하세요. 재발급하면 기존 확장 프로그램 설정의 토큰은 더 이상 작동하지 않습니다.
설정을 불러오는 중입니다.
