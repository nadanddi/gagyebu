# Google Sheets 다중 거래내역 업로더

`2026년 8월 통합 가계부`와 같은 구조의 Google Sheets에 연결하는 Apps Script입니다.

## 사용자 흐름

1. 스프레드시트의 `가계부` 메뉴에서 `거래내역 여러 파일 업로드`를 엽니다.
2. 본인 계좌이체를 식별할 이름과 대상 월을 확인합니다.
3. CSV, XLS, XLSX, PDF 파일을 한 번에 여러 개 선택합니다.
4. 분석 결과에서 파일별 은행, 기간, 건수를 확인합니다.
5. `가계부에 반영`을 누릅니다.

`가계부 → 새 월 등록`으로 월을 추가하고 `가계부 → 월별 대시보드 보기`에서 기준 월을 바꿉니다. 대시보드에는 월 합계, 소비 항목 원그래프, 일별 지출·입금이 표시됩니다.

브라우저에서는 여러 파일을 한 번에 선택하지만 Apps Script 제한을 피하기 위해 파일을 하나씩 순차 분석합니다. 분석이 모두 끝난 뒤 전체 결과를 한 번에 반영합니다.

## 처리 기준

- 본인 표시명이 들어간 계좌이체와 카드잔액 자동충전은 내부이체입니다.
- OK저축은행 출금과 같은 날짜·금액의 토스뱅크 `카드잔액 자동충전` 입금은 한 쌍의 내부이체로 맞춥니다. 두 기록은 각각 출금관리와 입금관리에 남고 지출·외부입금 합계에서는 제외됩니다.
- 상품권·온누리 충전은 충전일 지출입니다.
- 타인송금은 지출입니다.
- 입금과 환급은 출금과 별도로 관리합니다.
- 파일을 다시 올려도 날짜, 시간, 은행, 적요, 금액, 입출금 방향이 같은 거래는 추가하지 않습니다.
- 대상 월과 다른 거래는 기록하지 않고 결과와 가져오기 기록에 표시합니다.
- 원본 파일은 Drive의 `가계부_거래내역_가져오기/스프레드시트_업로드_원본`에 보관합니다.
- 임시 변환 파일은 처리 후 휴지통으로 이동합니다.

## 지원 범위

- CSV: UTF-8을 우선하고 깨진 문자가 있으면 EUC-KR로 다시 읽습니다.
- XLS/XLSX: Drive API로 임시 Google Sheet를 만들어 읽습니다.
- PDF: 일반 파일은 Drive API로 텍스트를 추출합니다. 암호화 PDF는 업로드 창에서 암호를 입력해 브라우저 안에서 해제하며, 암호는 Apps Script나 Drive에 전송·저장하지 않습니다. 텍스트가 없는 스캔형 암호화 PDF는 제외됩니다.
- 현재 은행별 파서는 토스뱅크, 우리은행 거래실적증명서, OK저축은행 형식을 기준으로 합니다.

암호화 PDF 해제에는 Mozilla PDF.js의 버전 고정 CDN 파일을 사용합니다. 암호화 XLS/XLSX는 Google Drive 변환 API가 비밀번호 입력을 지원하지 않으므로 별도 브라우저 해제 모듈을 추가해야 합니다.

## 네이버페이 사용처 확인

은행 적요에 실제 가맹점 대신 `네이버페이` 또는 `네이버파이낸셜`만 표시된 지출은 `네이버페이 확인대기` 시트에 자동으로 모입니다. 네이버페이 앱에서 날짜·시간·금액이 같은 거래를 찾아 `실제 사용처`, `소비분류`, 필요하면 `메모`를 적습니다. 분류를 고르면 월별 원그래프가 바로 갱신됩니다. `가계부 → 네이버페이 입력 반영`을 실행하면 분류와 실제 사용처가 출금관리에도 보존됩니다.

`naver-pay-extension/`을 설치하면 PC 결제내역의 모든 페이지와 상세 링크를 순회하여 위 입력을 자동화할 수 있습니다. 날짜·금액으로 후보를 찾고 시간이 가장 가까운 은행 거래에 매칭합니다. 매칭되지 않은 항목은 `네이버페이 동기화 기록`에 남깁니다.

파일당 8MB, 한 번 선택한 전체 파일은 25MB로 제한합니다. 스캔 PDF와 은행 양식 변경은 `분석실패` 또는 확인 경고가 날 수 있습니다.

## 배포

이 폴더를 `clasp`로 대상 Google Sheet에 연결한 뒤 푸시합니다. `.clasp.json`에는 개인 Apps Script 프로젝트 ID가 들어가므로 Git에 올리지 않습니다.

```powershell
clasp login
clasp create --type sheets --title "가계부 거래내역 업로더" --parentId "<SPREADSHEET_ID>"
clasp push
```

처음 스프레드시트를 다시 열 때 Google 권한 승인 후 `가계부 → 자동화 초기 설정`을 한 번 실행합니다.

네이버페이 자동 동기화는 추가로 `배포 → 새 배포 → 웹 앱`에서 배포해야 합니다. 가계부 메뉴의 `네이버페이 자동 동기화 설정`에서 발급한 토큰과 웹 앱의 `/exec` URL을 Chrome 확장 프로그램 옵션에 입력합니다.
