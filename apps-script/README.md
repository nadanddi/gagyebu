# Google Sheets 다중 거래내역 업로더

`2026년 8월 통합 가계부`와 같은 구조의 Google Sheets에 연결하는 Apps Script입니다.

## 사용자 흐름

1. 스프레드시트의 `가계부` 메뉴에서 `거래내역 여러 파일 업로드`를 엽니다.
2. 본인 계좌이체를 식별할 이름과 대상 월을 확인합니다.
3. CSV, XLS, XLSX, PDF 파일을 한 번에 여러 개 선택합니다.
4. 분석 결과에서 파일별 은행, 기간, 건수를 확인합니다.
5. `가계부에 반영`을 누릅니다.

브라우저에서는 여러 파일을 한 번에 선택하지만 Apps Script 제한을 피하기 위해 파일을 하나씩 순차 분석합니다. 분석이 모두 끝난 뒤 전체 결과를 한 번에 반영합니다.

## 처리 기준

- 본인 표시명이 들어간 계좌이체와 카드잔액 자동충전은 내부이체입니다.
- 상품권·온누리 충전은 충전일 지출입니다.
- 타인송금은 지출입니다.
- 입금과 환급은 출금과 별도로 관리합니다.
- 파일을 다시 올려도 날짜, 시간, 은행, 적요, 금액, 입출금 방향이 같은 거래는 추가하지 않습니다.
- 대상 월과 다른 거래는 기록하지 않고 결과와 가져오기 기록에 표시합니다.
- 원본 파일은 Drive의 `가계부_거래내역_가져오기/스프레드시트_업로드_원본`에 보관합니다.
- 임시 변환 파일은 처리 후 휴지통으로 이동합니다.

## 지원 범위

- CSV: UTF-8을 우선하고 깨진 문자가 있으면 EUC-KR로 다시 읽습니다.
- XLS/XLSX: Drive API로 임시 Google Sheet를 만들어 읽습니다.
- PDF: Drive API로 임시 Google Doc을 만들어 텍스트를 추출합니다.
- 현재 은행별 파서는 토스뱅크, 우리은행 거래실적증명서, OK저축은행 형식을 기준으로 합니다.

파일당 8MB, 한 번 선택한 전체 파일은 25MB로 제한합니다. 스캔 PDF와 은행 양식 변경은 `분석실패` 또는 확인 경고가 날 수 있습니다.

## 배포

이 폴더를 `clasp`로 대상 Google Sheet에 연결한 뒤 푸시합니다. `.clasp.json`에는 개인 Apps Script 프로젝트 ID가 들어가므로 Git에 올리지 않습니다.

```powershell
clasp login
clasp create --type sheets --title "가계부 거래내역 업로더" --parentId "<SPREADSHEET_ID>"
clasp push
```

처음 스프레드시트를 다시 열 때 Google 권한 승인 후 `가계부 → 자동화 초기 설정`을 한 번 실행합니다.
