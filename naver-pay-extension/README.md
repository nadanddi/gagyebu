# 네이버페이 가계부 동기화 Chrome 확장 프로그램

로그인된 네이버페이 결제내역과 각 결제의 상세 페이지를 읽어 실제 매장, 상품, 결제시각과 금액을 정리합니다. 네이버 아이디나 비밀번호를 입력받지 않으며 Chrome에 이미 로그인된 세션만 사용합니다.

## 여러 페이지에서 월 전체 내역 찾기

1. `https://pay.naver.com/pc/history`에서 선택한 탭의 1페이지부터 확인합니다.
2. 목록 한 페이지에 있는 결제 상세 링크를 차례로 읽습니다.
3. 선택한 월보다 최신인 내역은 건너뛰면서 다음 페이지로 이동합니다.
4. 선택한 월의 내역을 모두 모으고, 그보다 오래된 달의 거래가 나오면 순회를 끝냅니다.
5. 네이버 화면의 페이지 묶음과 상관없이 최대 100페이지까지 확인합니다.

`전체`, `쇼핑`, `현장결제` 등 현재 열어 둔 탭의 조건을 유지합니다. 8월 내역이 첫 화면에 보이지 않아도 월 선택란에서 `2026-08`을 고르면 확장 프로그램이 이전 페이지들을 자동으로 확인합니다.

## 로컬 설치

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 폴더를 선택합니다.
4. 코드를 갱신한 뒤에는 확장 프로그램 카드의 새로고침 버튼을 누릅니다.
5. 이미 열어 둔 네이버페이 결제내역 페이지도 새로고침합니다.

## 배포 전 로컬 시험

Apps Script 웹 앱 주소와 토큰을 설정하지 않은 상태에서는 버튼이 `네이버페이 내역 CSV 저장`으로 표시됩니다. 선택한 월의 여러 페이지를 순회한 결과를 UTF-8 CSV로 내려받으므로 실제 매장, 상품, 시간과 금액이 정확한지 먼저 확인할 수 있습니다.

웹 앱을 나중에 배포하고 실행 URL과 토큰을 옵션에 저장하면 같은 버튼이 가계부 직접 동기화 기능으로 동작합니다. 상세내역은 가계부에서 같은 날짜·금액의 네이버페이 출금을 찾아 사용처를 채우며, 일치하지 않는 건은 `네이버페이 동기화 기록`에 남깁니다.

## 보안

- 네이버 로그인 정보와 쿠키를 저장하거나 Apps Script로 전송하지 않습니다.
- 결제일시, 결제번호, 실제 매장, 상품, 금액과 상세 페이지 주소만 처리합니다.
- 동기화 토큰과 웹 앱 URL은 Chrome 로컬 확장 프로그램 저장소에만 저장합니다.
- 내려받은 실제 결제 CSV는 공개 GitHub 저장소에 올리지 않습니다.
