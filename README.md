# 가계부

여러 컴퓨터에서 이어서 개발하는 개인 가계부 프로젝트입니다.

## 작업 이어가기

1. GitHub에 저장된 최신 변경을 받아옵니다. 로컬 변경이 있으면 먼저 확인합니다.
2. `AGENTS.md`와 `WORK_LOG.md`를 읽습니다.
3. 작업 후 진행 기록을 갱신하고 변경 파일을 커밋하여 GitHub에 푸시합니다.

대화 전체가 자동으로 동기화되는 것은 아닙니다. 요구사항, 결정 사항, 진행 상황을 파일에 기록합니다.

## 현재 상태

2026년 8월 은행별 엑셀·PDF 거래내역을 통합한 새 Google Sheets 가계부를 만들었습니다.
평소에는 대시보드, 출금관리, 입금관리 탭을 사용합니다. 월간요약, 원본대조, 월목록은 계산·검증용으로 숨겨 두었으며 분류 변경은 요약과 대시보드에 반영됩니다.
구조와 가져오기 원칙은 `docs/LEDGER_SPEC.md`에 정리되어 있습니다.

## 거래내역 여러 파일 업로드

`apps-script/`에는 Google Sheets 안에서 CSV, XLS, XLSX, PDF 파일을 여러 개 선택해 분석하고 한 번에 반영하는 Apps Script가 있습니다.
본인계좌 이체와 중복 거래를 제외하고, 원본 파일과 처리 결과를 Drive에 기록하도록 구성했습니다.
월 선택형 대시보드, 소비 항목 원그래프, 일별 총지출 달력, 새 월 등록, 네이버페이 상세내역 직접 연동을 포함합니다. 달력은 총지출을 크게 표시하고 날짜나 금액에 마우스를 올리면 시간·사용처·금액·분류를 보여줍니다. 암호화 PDF는 업로드 창에서 암호를 받아 브라우저 안에서 해제하며 암호를 저장하지 않습니다.

`naver-pay-extension/`에는 로그인된 네이버페이 결제내역의 상세 페이지를 순회해 실제 매장·상품·금액을 `출금관리` 거래와 자동 매칭하는 로컬 Chrome 확장 프로그램이 있습니다. 사용처와 확실한 소비분류는 해당 출금 행에 직접 반영되고, 애매한 분류는 `기타·확인필요`로 남습니다. 로그인 정보와 쿠키는 전송하지 않으며 Apps Script 웹 앱과 임의 토큰으로 연결합니다.

현재 Apps Script 코드는 기존 통합 가계부에 본인용으로 연결되어 있습니다. 로컬 Chrome 확장 프로그램으로 여러 페이지에 걸친 2026년 8월 네이버페이 CSV를 저장하고, 은행 출금과 실제 사용처를 맞춰 가계부에 반영했습니다. 웹 앱 배포와 Chrome 스토어 공개는 보류합니다.
