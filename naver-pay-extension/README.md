# 네이버페이 가계부 동기화 Chrome 확장 프로그램

로그인된 네이버페이 결제내역의 목록 페이지와 각 상세 페이지를 읽어 Google Sheets 가계부의 `네이버페이 확인대기`와 맞춥니다. 네이버 아이디나 비밀번호를 입력받지 않으며, Chrome에 이미 로그인된 세션만 사용합니다.

## 동작 방식

1. `https://pay.naver.com/pc/history`의 페이지 수와 상세 링크를 찾습니다.
2. 각 상세 페이지에서 결제일시, 결제번호, 실제 매장, 상품, 총액을 읽습니다.
3. Apps Script 웹 앱에 결과를 보냅니다.
4. 가계부의 날짜·금액이 같은 네이버페이 출금을 찾고, 여러 후보가 있으면 시간이 가장 가까운 거래를 선택합니다.
5. 실제 사용처와 상품을 `네이버페이 확인대기`에 기록합니다. 분류 규칙이 확실한 경우에만 소비분류를 자동 입력합니다.
6. 일치하지 않는 상세내역은 `네이버페이 동기화 기록`에 남깁니다.

## 로컬 설치

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드합니다`를 누르고 이 폴더를 선택합니다.
4. Google Sheets에서 Apps Script를 연결하고 `실행 사용자: 본인`, `액세스 사용자: 모든 사용자`인 웹 앱으로 배포합니다. 웹 앱은 별도 임의 토큰이 맞는 요청만 처리합니다.
5. 가계부 메뉴의 `네이버페이 자동 동기화 설정`에서 토큰을 복사합니다.
6. 확장 프로그램의 `세부정보 → 확장 프로그램 옵션`에 웹 앱 실행 URL과 토큰을 저장합니다.
7. 네이버페이 결제내역 페이지를 새로고침하고 오른쪽 아래에서 대상 월을 선택한 뒤 `가계부 자동 동기화`를 누릅니다.

확장 프로그램은 현재 결제내역의 모든 페이지를 순회합니다. 네이버페이 화면 구조가 바뀌어 상세 링크나 필드가 인식되지 않으면 동기화를 중단하고 화면에 오류를 표시합니다.

## 보안

- 네이버 로그인 정보와 쿠키를 저장하거나 Apps Script로 전송하지 않습니다.
- Apps Script에는 결제일시, 결제번호, 실제 매장, 상품, 금액, 상세 페이지 주소만 전송합니다.
- 웹 앱은 가계부에서 발급한 임의 토큰이 맞는 요청만 처리합니다.
- 토큰과 웹 앱 URL은 Chrome의 로컬 확장 프로그램 저장소에만 저장합니다.
- 저장소에는 실제 토큰, 웹 앱 URL, 거래내역을 포함하지 않습니다.
